# 微信扫码功能使用说明

## 功能概述

本项目已集成微信JS-SDK扫码功能，支持在微信内置浏览器中调用微信原生扫码能力。

## 技术实现

### 前端实现
  /views/pages/index/index

  - `isWechat()`: 检测是否在微信内置浏览器中
  - `configWechatSDK()`: 配置微信JS-SDK
  - `onScan()`: 执行扫码操作

### 后端实现
- 控制器：`gkzh-admin/src/main/java/com/gkzh/web/controller/common/WeixinController.java`
- 工具类：`gkzh-admin/src/main/java/com/gkzh/common/utils/WeixinJssdkUtil.java`
- 接口：`/api/common/jssdk/config`

## 配置步骤

### 1. 微信公众号配置

在 `application.yaml` 中配置您的微信公众号信息：

```yml
app:
  wx_appId: "xxxxxxxxxxxxx"
  wx_appSecret: "xxxxxxxxxxxx"
```


### 2. 获取微信公众号AppID和AppSecret

1. 登录微信公众平台：https://mp.weixin.qq.com/
2. 进入"开发" -> "基本配置"
3. 获取AppID和AppSecret

### 3. 配置JS接口安全域名

1. 在微信公众平台进入"设置" -> "公众号设置" -> "功能设置"
2. 配置"JS接口安全域名"为您的网站域名
3. 域名必须是备案过的，且使用HTTPS协议

## 使用方法

### 前端调用

```javascript

// 在页面加载时初始化
onLoad() {
    this.initWechatSDK(); 
}

initWechatSDK() {
    // 检查是否在微信环境中
    if (!this.isWechat()) {
        console.warn('非微信环境，跳过微信SDK初始化');
        return;
    }

    // 使用官方推荐的方式加载微信SDK
    try {
        jWeixin = require('jweixin-module');
        wxLoaded = true;
        console.log('微信SDK加载成功');
        this.configWechatSDK();
    } catch (e) {
        console.warn('微信SDK加载失败:', e);
        // uni.showToast({title:'微信SDK加载失败',icon: 'loading',duration: 5000});
        wxLoaded = false;
    }

},
isWechat() {
    // 检测是否在微信浏览器中
    const ua = navigator.userAgent.toLowerCase();
    return ua.indexOf('micromessenger') > -1;
},
configWechatSDK() {
    // 首先从服务器获取配置信息
    const url = window.location.href.split('#')[0];
    getJsSdkConfig(url).then(res=>{
        const config = res.data
        uni.showToast({
            title: res.msg,
            icon: 'loading',
            duration: 5000
        });
        console.log(config)
        jWeixin.config({
            debug: false , // 开启调试模式
            appId: config.appId, // 必填，公众号的唯一标识
            timestamp: config.timestamp, // 必填，生成签名的时间戳
            nonceStr: config.nonceStr, // 必填，生成签名的随机串
            signature: config.signature, // 必填，签名
            jsApiList: [
                'scanQRCode', // 微信扫码API
                'chooseImage', // 拍照或从手机相册中选图
                'previewImage', // 预览图片
                'uploadImage', // 上传图片
                'downloadImage' // 下载图片
            ]
        })

        jWeixin.ready(() => {
            // uni.showToast({title:'初始化成功',icon: 'loading',duration: 5000});
            console.log('微信JS-SDK 初始化成功')
        })

        jWeixin.error((err) => {
            // uni.showToast({title:'初始化失败',icon: 'loading',duration: 5000});
            console.error('微信JS-SDK 初始化失败', err)
        })
    })
},
onScan() {
    // 检查微信SDK是否可用
    if (!jWeixin || !wxLoaded) {
        uni.showToast({
            title: '微信SDK未加载完成，请稍后重试',
            icon: 'none'
        });
        return;
    }

    // 检查是否在微信环境中
    if (!this.isWechat()) {
        uni.showToast({
            title: '请在微信中打开',
            icon: 'none'
        });
        return;
    }

    // 使用微信SDK的扫码功能
    jWeixin.scanQRCode({
        needResult: 1, // 默认为0，扫描结果由微信处理，1则直接返回扫描结果
        scanType: ["qrCode","barCode"], // 可以指定扫二维码还是一维码，默认二者都有
        success: (res) => {
            console.log('微信扫码结果:', res.resultStr);
            uni.showToast({
                title: '扫码成功',
                icon: 'success'
            });
            // 处理扫码结果
            this.handleScanResult(res.resultStr);
        },
        fail: (err) => {
            console.error('微信扫码失败:', err);
            uni.showToast({
                title: '扫码失败',
                icon: 'none'
            });
        }
    });
}
```

### 后端接口

接口地址：`GET /api/common/jssdk/config`

请求参数：
- `url`: 当前页面URL（不包含#号后面的部分）

响应示例：
```json

    "code": 200,
    "msg": "操作成功",
    "data": {

        "timestamp": 1640995200,
        "nonceStr": "gkzh_1640995200_123",

```

## 环境兼容性

### 微信内置浏览器
- 使用微信JS-SDK的 `wx.scanQRCode` 方法
- 需要配置JS接口安全域名
- 支持扫码和条形码

### 其他环境
- 使用uni-app的 `uni.scanCode` 方法
- 支持H5、小程序、App等平台

## 注意事项

1. **域名配置**：必须在微信公众平台配置JS接口安全域名
2. **HTTPS要求**：微信JS-SDK要求使用HTTPS协议
3. **签名验证**：后端会自动生成正确的签名，确保安全性
4. **缓存机制**：access_token和jsapi_ticket会自动缓存，避免频繁请求
5. **错误处理**：前端已集成完整的错误处理机制

## 常见问题

### Q: 扫码功能在微信中无法使用？
A: 检查以下几点：
- 是否配置了正确的AppID和AppSecret
- 是否在微信公众平台配置了JS接口安全域名
- 是否使用HTTPS协议访问
- 域名是否已备案

### Q: 签名验证失败？
A: 检查以下几点：
- 当前页面URL是否与签名时的URL一致
- 时间戳是否在有效期内
- 后端签名算法是否正确

### Q: 在非微信环境中如何使用？
A: 系统会自动检测环境，在非微信环境中使用uni.scanCode方法，无需额外配置。
