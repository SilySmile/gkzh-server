# 学生端抽奖接口使用说明

## 接口概述

本文档描述了学生端抽奖转盘奖品列表接口的使用方法。

## 接口详情

### 获取转盘奖品列表

**接口地址：** `GET /api/lottery/prizes/{activityId}`

**请求参数：**
- `activityId` (路径参数): 活动ID，必填

**响应格式：**
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": [
    {
      "prize_id": 1,
      "title": "一等奖",
      "image_url": "/static/lottery/fangche.png",
      "probability": 0.05
    },
    {
      "prize_id": 2,
      "title": "二等奖", 
      "image_url": "/static/lottery/huwaishoubiao.png",
      "probability": 0.10
    }
  ]
}
```

**响应字段说明：**
- `prize_id`: 奖品ID
- `title`: 奖品名称
- `image_url`: 奖品图片URL
- `probability`: 中奖概率（0-1之间的小数）

## 前端使用示例

### 1. API调用

```javascript
// 在 gkzh-app/api/lottery.js 中
import request from '../utils/request.js'

export function getPrizeList(activityId) {
  return request({
    url: `/api/lottery/prizes/${activityId}`,
    method: 'GET'
  });
}
```

### 2. 页面中使用

```javascript
// 在转盘页面中
import { getPrizeList } from '../../api/lottery.js'

export default {
  data() {
    return {
      prizes: [],
      loading: true,
      error: null,
      activityId: null
    }
  },
  
  onLoad(options) {
    this.activityId = options.activityId || 1;
    this.loadPrizes();
  },
  
  methods: {
    async loadPrizes() {
      this.loading = true;
      this.error = null;
      
      try {
        const response = await getPrizeList(this.activityId);
        if (response.code === 200) {
          this.prizes = response.data || [];
          if (this.prizes.length === 0) {
            this.error = '暂无奖品数据';
          }
        } else {
          this.error = response.msg || '获取奖品失败';
        }
      } catch (err) {
        console.error('加载奖品失败:', err);
        this.error = '网络错误，请检查网络连接';
      } finally {
        this.loading = false;
      }
    }
  }
}
```

## 项目配置

在 `gkzh-app/config/api.js` 中配置不同环境的API地址：

```javascript

  BASE_URL: 'http://localhost:8080',
  TIMEOUT: 10000
};

// 生产环境配置
const PROD_CONFIG = {
  BASE_URL: 'https://your-production-domain.com',
  TIMEOUT: 10000
};
```

## 页面跳转

在跳转到转盘页面时，需要传递活动ID参数：

```javascript
// 跳转到转盘页面
uni.navigateTo({
  url: `/pages/lottery/index?activityId=1`
})
```

## 错误处理

接口包含完整的错误处理机制：

1. **加载状态**：显示"加载中..."提示
2. **网络错误**：显示"网络错误，请检查网络连接"
3. **数据为空**：显示"暂无奖品数据"
4. **重试机制**：提供重试按钮
5. **Token过期**：自动清除本地token并提示重新登录

## 注意事项

1. 确保后端服务正常运行
2. 检查数据库连接和表结构
3. 验证图片资源路径是否正确
4. 测试不同活动ID的数据返回
5. 确保学生端认证机制正常工作
6. 根据实际环境修改 `config/api.js` 中的BASE_URL

## 环境配置

### 开发环境
- 修改 `gkzh-app/config/api.js` 中的 `DEV_CONFIG.BASE_URL`
- 确保后端服务运行在对应端口

### 生产环境
- 修改 `gkzh-app/config/api.js` 中的 `PROD_CONFIG.BASE_URL`
- 确保域名和HTTPS配置正确
