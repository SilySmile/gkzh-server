部署记录：
# 1. 运行一个容器
docker run -d --name gkzh -v /www/gkzh/backend:/app -w /app -p 8082:8080 openjdk:17.0.2 java -jar gkzh-admin.jar
目录结构：
```sh
/www/gkzh/backend/
├── config
│    └── application.yaml
├── gkzh-admin.jar
└── uploadPath
```

# 2. 配置文件 application.yml
```yml
server:
  port: 8080
gkzh:
  profile: /app/uploadPath
spring:
  datasource:
    druid:
      master:
        url: jdbc:mysql://172.17.0.1:8306/gkzh?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=false&serverTimezone=GMT%2B8
  redis:
    host: 172.17.0.1
```
