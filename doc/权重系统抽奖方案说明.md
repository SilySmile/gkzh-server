# 权重系统抽奖方案说明

## 方案概述

为了解决原有概率系统设置复杂、容易出错的问题，我们设计了基于权重的抽奖系统。权重系统更加直观、灵活，便于管理和调整。

## 权重系统 vs 概率系统对比

### 原有概率系统的问题
1. **设置复杂**：每次设置奖品时都需要手动计算概率总和为1
2. **容易出错**：概率计算错误会导致系统异常
3. **调整困难**：修改一个奖品概率需要重新计算所有概率
4. **不够直观**：概率数值难以理解奖品的重要性

### 权重系统的优势
1. **设置简单**：直接设置权重数值，系统自动计算概率
2. **直观易懂**：权重数值越大，中奖概率越高
3. **调整灵活**：修改单个奖品权重不影响其他奖品
4. **扩展性强**：支持奖品类型分类、启用状态控制等功能

## 概率计算逻辑

### 权重转概率公式
```
实际概率 = 奖品权重 / 总权重
```

### 示例计算
- 特等奖权重：1
- 一等奖权重：3
- 二等奖权重：8
- 三等奖权重：15
- 四等奖权重：25
- 谢谢参与权重：100

**总权重** = 1 + 3 + 8 + 15 + 25 + 100 = 152

**各奖品概率**：
- 特等奖：1/152 ≈ 0.66%
- 一等奖：3/152 ≈ 1.97%
- 二等奖：8/152 ≈ 5.26%
- 三等奖：15/152 ≈ 9.87%
- 四等奖：25/152 ≈ 16.45%
- 谢谢参与：100/152 ≈ 65.79%

## 权重设置建议

### 权重数值参考
- **特等奖**：1-5（极低概率）
- **一等奖**：3-10（低概率）
- **二等奖**：8-20（较低概率）
- **三等奖**：15-30（中等概率）
- **四等奖**：25-50（较高概率）
- **谢谢参与**：50-200（高概率）

### 设置原则
1. **比例关系**：权重数值反映奖品价值比例
2. **总权重**：建议总权重在100-500之间
3. **梯度设置**：相邻等级权重要有明显差异
4. **库存考虑**：库存少的奖品权重可以适当降低

## 奖品类型说明

### 奖品类型分类
- **1-实物奖品**：如手机、手表等实体物品
- **2-虚拟奖品**：如优惠券、积分等虚拟物品
- **3-谢谢参与**：未中奖的安慰奖

### 启用状态控制
- **0-禁用**：该奖品不参与抽奖
- **1-启用**：该奖品正常参与抽奖

### 权重调整工具
```javascript
// 权重调整示例
function adjustWeights(prizes, targetTotalWeight) {
  const currentTotal = prizes.reduce((sum, prize) => sum + prize.weight, 0);
  const ratio = targetTotalWeight / currentTotal;
  
  prizes.forEach(prize => {
    prize.weight = Math.round(prize.weight * ratio);
  });
  
  return prizes;
}
```

## 总结

权重系统相比概率系统具有以下优势：

1. **易用性**：设置简单，无需复杂计算
2. **灵活性**：支持奖品类型分类和启用状态控制
3. **直观性**：权重数值直接反映奖品重要性
4. **稳定性**：减少人为计算错误
5. **扩展性**：支持后续功能扩展

建议采用权重系统替代原有的概率系统，这将大大提升抽奖功能的管理效率和用户体验。
